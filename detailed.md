# Project Overview

This document provides a detailed overview of the codebase, outlining the purpose and functionality of key files and directories.

## Directory: `src/components/prescription-doctor`

- `<mcfile name="prescription-time-display.tsx" path="src/components/prescription-doctor/prescription-time-display.tsx"></mcfile>`: This React component displays the creation date, valid until date, and optionally the filled date of a prescription. It uses `date-fns` for formatting and `lucide-react` icons. The "valid until" date is dynamically colored based on its proximity to expiration.

## Directory: `src/components/prescription-patient`

The `src/components/prescription-patient` directory is currently empty but is intended to house patient-facing components related to prescriptions.

## Directory: `src/components/shop`

- `<mcfile name="index.ts" path="src/components/shop/index.ts"></mcfile>`: This file serves as an export hub for shop-related components and types. It exports `ProductCard`, `ShoppingCart`, `PaymentForm`, and `OrderHistory` components, along with their respective types: `CartItem`, `Order`, `OrderItem`, and `PaymentMethod`.
- `<mcfile name="OrderHistory.tsx" path="src/components/shop/OrderHistory.tsx"></mcfile>`: This React component displays a user's order history. It includes features like filtering, viewing order details, reordering, downloading invoices, and tracking orders. It utilizes `shadcn/ui` components (e.g., `Card`, `Button`, `Badge`, `Separator`) and `lucide-react` icons. The component also includes sample order data for demonstration.
- `<mcfile name="PaymentForm.tsx" path="src/components/shop/PaymentForm.tsx"></mcfile>`: This React component provides a secure payment form, supporting credit/debit cards, PayPal, and Apple Pay. It handles input formatting for card numbers and expiry dates, simulates payment processing, and utilizes `shadcn/ui` components (e.g., `Card`, `Button`, `Input`, `Label`, `Badge`, `Separator`) and `lucide-react` icons.
- `<mcfile name="ShoppingCart.tsx" path="src/components/shop/ShoppingCart.tsx"></mcfile>`: This React component displays a user's shopping cart. It allows users to update item quantities, remove items, and proceeds to a simulated checkout process. It calculates and displays the subtotal, tax, shipping, and total. The component uses `shadcn/ui` components (e.g., `Card`, `Button`, `Badge`, `Separator`) and `lucide-react` icons, and includes sample cart data.
- `<mcfile name="productCard.tsx" path="src/components/shop/productCard.tsx"></mcfile>`: This React component is responsible for displaying individual product information. It shows the product's name, description, price, image, category, and stock status. It also indicates if a prescription is required for the product. The component uses `shadcn/ui` `Card`, `Button`, and `Badge` components and provides "View Details" and "Add to Cart" (or "Upload Prescription" for prescription-required items) actions.

## Directory: `src/components/subscription`

- `<mcfile name="index.ts" path="src/components/subscription/index.ts"></mcfile>`: This file acts as an export hub for various subscription-related components. It exports `SubscriptionDashboard`, `SubscriptionHeader`, `SubscriptionPlanCard`, `SubscriptionCurrentOverview`, `SubscriptionBenefitsGrid`, `SubscriptionBillingToggle`, `SubscriptionComparisonTable`, `SubscriptionUsageStats`, `SubscriptionPaymentHistory`, and `SubscriptionRecommendations`, along with their mobile or compact variations.
- `<mcfile name="subscription-benefits-grid.tsx" path="src/components/subscription/subscription-benefits-grid.tsx"></mcfile>`: This file defines two React components: `SubscriptionBenefitsGrid` and `SubscriptionBenefitsCompact`. `SubscriptionBenefitsGrid` displays subscription benefits in a grid format using `shadcn/ui` `Card` components, while `SubscriptionBenefitsCompact` provides a mobile-friendly, compact list view. Both components utilize a `SubscriptionBenefit` type and dynamically style categories.
- `<mcfile name="subscription-billing-toggle.tsx" path="src/components/subscription/subscription-billing-toggle.tsx"></mcfile>`: This file defines two React components: `SubscriptionBillingToggle` and `SubscriptionBillingToggleProminent`. Both components allow users to switch between monthly and yearly billing cycles and display potential savings for yearly plans. They utilize `shadcn/ui` `Button` and `Badge` components, with `SubscriptionBillingToggleProminent` offering a more emphasized savings display.
- `<mcfile name="subscription-comparison-table.tsx" path="src/components/subscription/subscription-comparison-table.tsx"></mcfile>`: This file defines two React components: `SubscriptionComparisonTable` and `SubscriptionComparisonMobile`. `SubscriptionComparisonTable` displays a comparison table of subscription plans, including features, prices, and a "Select" button, using `shadcn/ui` components and `lucide-react` icons. It dynamically calculates prices based on the billing cycle and highlights the current plan. `SubscriptionComparisonMobile` provides a mobile-friendly card-based view of the subscription plans, also using `shadcn/ui` components and highlighting current and popular plans.
- `<mcfile name="subscription-current-overview.tsx" path="src/components/subscription/subscription-current-overview.tsx"></mcfile>`: This React component displays a user's current subscription status and usage. It shows the current plan name, status, price, billing cycle, and usage statistics for consultations and medicine savings. It also provides billing information, including the next billing date and payment method, and action buttons for upgrading, canceling, or viewing invoices. It uses `shadcn/ui` components like `Card`, `Badge`, `Button`, and `Progress`, along with `lucide-react` icons.
